# Tracebird plugin

The Tracebird MCP server (`https://tracebird.io/mcp`, OAuth sign-in) plus skills for performance reviews, cutting wasted spend, automation rules, split tests, tracking setup, reports and workspace administration. Works in Claude Code, OpenAI Codex and Grok Build.

Install everywhere with `curl -fsSL https://tracebird.io/install.sh | sh`, or see the [marketplace README](../../README.md) for per-agent commands.
